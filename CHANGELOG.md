# Changelog - World PvP Police Guild - Discord

## v0.1.0 - non publiée

- Le module Discord de World PvP Police Guild : les appels, les « J'arrive » et les « C'est réglé »
  sur le Discord de la guilde, ou dans le chat de guilde quand elle est en chat fusionné.
- `/wpp discord`, `/wpp fusion on|off` et une case dans la page d'options de l'addon.
- Interface traduite en anglais, allemand et espagnol.
